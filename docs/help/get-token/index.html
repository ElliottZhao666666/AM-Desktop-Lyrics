Apple Music Token 设置说明

AMDL 的官方逐字歌词渠道需要授权信息。设置中的两个字段对应请求头 Authorization 和 Media-User-Token；普通客户端缓存和 QQ 音乐渠道不依赖用户 Token。

填写自己的授权信息

  1. 在自己的浏览器打开 Apple Music 网页播放器，登录自己的账户并播放可用歌曲。
  2. 打开浏览器开发者工具的 Network（网络）面板，刷新页面，查看播放器发出的 Apple Music 请求。可尝试按 amp-api.music.apple.com 筛选。
  3. 在请求头中找到 Authorization 和 Media-User-Token。网页版本和请求类型可能不同，并非每个请求都有这两个字段。
  4. 在 AMDL「歌词渠道」展开 Token 设置，将授权值填入对应字段。Authorization 包含 Bearer 前缀时保留完整值。
  5. 点击「保存并生效」。当前歌曲会重新检索歌词；歌词不存在、账户授权或接口限制仍可能导致没有逐字结果。

Token 会过期。遇到授权失败时，重新登录网页播放器并更新设置。不要把 Token 粘贴进公开 Issue、日志截图或主题文件。

开发者接入

开发者 Token 与用户 Token 的正式获取流程请参阅 Apple MusicKit 用户授权文档。AMDL 目前不提供应用内登录或自动续期。
