## 同时修复的可靠性问题

- **缓存与繁简开关：** 通用设置与 API 的 autoChs 统一；缓存保留原始文本，在展示时转换。切换转换设置立即刷新，清除依赖旧本地化参数的 API 缓存；降低上限立即截断。缓存版本升级，旧解析结果重新获取。
- **永久池：** 键包含专辑，兼容查找旧记录时仍核对专辑；以原子替换写入，避免覆盖文件时中断损坏。
- **设置关闭：** 取消和标题栏关闭丢弃未保存编辑，重新打开读取最新持久化值；实时偏移只回滚本窗口产生的修改。回滚 IPC 使用 expectedRevision，在后端锁内核验，避免覆盖同时发生的控制条调整。
- **字体枚举：** 覆盖 HKLM 和 HKCU，拆分组合显示名；单条注册表项失败不再阻断设置加载。这里只选择已安装字体，不加载字体文件。
- **歌词展示：** 歌词最终结束后显示曲目信息，不再永久停留最后一行；当前行二分定位，重叠行检索利用结束时间索引。缺失最后一行结束时间时优先使用当前媒体时长。
- **默认主题：** Rust 与前端共用 `src/default-theme.css`；测试检查其与默认编辑值一致。显式清除关闭状态下的描边、阴影，避免活动字形继承普通字形的效果。
- **窗口保存：** 单个后台写入线程防抖，避免每个移动、缩放事件创建新线程。
- **播放控制：** command 改为异步，WinRT 等待放在初始化 COM 的后台线程，前端等待上限 5 秒。超时不自动重复发送操作；底层 WinRT 调用已经发出时仍可能稍后完成。
- **日志：** 增加本地时间戳和时区；每份文件上限 4 MiB，单条记录限长；界面只读取最近 512 KiB。Windows 轮转前关闭句柄。
- **双开：** 接入 Tauri 官方单实例插件，作为首个插件注册；重复启动唤回既有主窗口及解锁窗口。依赖锁定在 Cargo.lock，未更新已有依赖版本。参考 [Tauri 单实例文档](https://v2.tauri.app/plugin/single-instance/)。
- **文档：** 修正 README 克隆命令、下载、反馈链接及 Rust 版本要求，调整普通 LRC、字体选择和开发进度描述；新增 `docs/help/get-token/index.html` 对应现有帮助链接。线上帮助页面仍需要正常发布静态官网。
